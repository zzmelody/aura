# 工作流编辑

工作流编辑器中间显示 Agent 绘制的 SVG 流程图，右侧常驻生成助手。没有代码标签页或顶部助手按钮。窄屏时画布和对话上下排列。

在右侧发送「分析当前流程」或描述修改需求。Agent 通过现有 DSH 对话分析当前源码，直接生成包含中文步骤、分支与连线的 SVG。完整回复会自动更新画布；前端不解析 Flow 代码，也不构建节点图。画布支持平移、缩放、适应窗口和导出 SVG。导出的图片使用当前主题颜色。

打开工作流不会自动发起模型请求。尚未分析时显示空状态；分析失败、输出不完整或 SVG 不符合静态展示限制时，可以在同一对话中要求重新生成，不会自动重发。SVG 不允许脚本、HTML、事件、CSS、动画、链接或外部资源。生成内容仍取决于模型的语义理解，不能当作运行验证。

分析绑定当前流程及源码版本。切换流程或改动代码后，旧回复无法覆盖当前画布。最近八份源码与 SVG 配对保存在本机独立缓存，原有 `aura.flow-draft.v1` 草稿格式保持不变。撤销替换或重新打开同一份源码时可恢复对应图片。仅分析不改代码；修改流程时必须同时返回完整 Flow 代码和有效 SVG，才更新本地草稿。

源码上下文最多提供前 7000 字符，超限会明确告知 Agent 分析范围，并禁止用截断上下文生成的代码替换草稿。较长流程可先拆分。菜单保留导入、导出代码和撤销操作；已注册流程仍通过原有运行入口执行，本地草稿需导出并注册后运行。

本地演示模式没有真实 Agent 分析能力。自动测试使用合成 SVG 验证显示、版本隔离、恢复与布局，不代表真实模型的分析质量。
