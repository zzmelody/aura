# Aura 主题规范

方向：紧凑的创作工作台。深色「夜航」使用中性炭灰底色，浅色「晨雾」使用暖白底色；淡紫只用于当前选项和重点操作。以细分隔线、固定工具栏和独立滚动区域建立层级，减少卡片套叠与装饰占位。

唯一颜色与排版来源是 `packages/frontend/ui/src/theme.ts`，通过 `@aura/ui/theme` 导出；页面与组件通过主题上下文消费，不单独维护浅色页面。基础组件直接渲染标准 HTML 与 SVG，浏览器、Electron renderer 和 Capacitor WebView 使用同一套 CSS 语义。

## 字体与尺寸

英文与数字使用 Manrope，标题 600、正文 400、控件 500；微型栏目编号与状态使用 IBM Plex Mono 400。字体以 Fontsource 的 Latin 子集随 Vite 产物和原生包分发，不依赖外部字体网络请求。中文回退到设备中文字体，避免额外打包大型中文字库。

主标题 28/38，页面标题 21/30，正文 14/23，说明文字 12/20。工作区控件以 11–13px 为主，代码为 IBM Plex Mono 12/23。主要间距级别为 4、8、12、16、24、32。顶栏从 72px 压缩为 48px，取消原有 1200px 总宽度限制。

## 组件

主要按钮提供默认、按下、禁用状态；次要按钮使用卡片色和细边。桌面图标按钮为 30–34px，主要按钮为 34–40px；触屏工作台操作扩大到至少 40px，并带明确的无障碍标签。卡片、主题选项、开关、输入框、对话气泡、生成状态与复制反馈使用统一语义颜色。Codex 入口位于右上角，用紧凑状态按钮展示未登录、登录中和已登录状态；授权细节放在模态面板中，设备码必须支持复制。

对话区将用户气泡右对齐、回复左对齐。输入区固定在底部，模型选择与发送操作合并在一行。逐字生成期间显示停止按钮；停止、网络错误和重试均为实际状态。主题设置中的「主题实验室」可直接查看字体、色板与动态效果。

联网对话在输入框下增加紧凑的「模型 / 思考」设置行，使用后端 DSH 目录与原生可键盘操作的下拉框，右侧标注「仅本会话」。默认选项显示实际模型与档位；配置按会话保存，生成中禁用，不改变工作流 Agent。窄屏自动换行并扩大触控区域；目录加载失败显示重试，已保存的型号或档位不可用时明确提示。

## 动效

按压缩放约 110ms，入场透明度与 12px 位移约 420ms，轨道慢旋转 24 秒一周。装饰轨道与消息入场分开处理；流式文本不重复播放整段入场动画。

「减少动态效果」或系统的减少动态效果设置会关闭轨道旋转和入场过渡；按钮仍保留即时反馈。动画不能代替文字状态。主题选择、开关和导航提供可访问标签，键盘可发送或 Shift+Enter 换行。

## 信息架构

参考 Codex：对话是首页，工作流是底层能力，工作台是面向任务的便捷入口。

- 默认进入新对话。空态居中显示 28/38 标题与快捷卡（可运行工作流、工作台、普通提问），对话列最大 820px。
- 工作台与对话、工作流平级，直接由 App 渲染，不再挂在工作流列表页。三个工作台共用 `.studio-shell`：232px 项目栏 + 主区；主区顶部固定 52px 工具条（返回、项目标题与保存状态、操作），内容在 `.studio-scroll` 中独立滚动。900px 以下项目栏收起，工具条出现项目下拉。工作台页签使用分段控件，强调色统一取 `--accent` / `--primary`，不再使用各自的私有色或衬线标题。离开有未保存修改的工作台需要确认。

## 工作流输出

- 每次运行是一张圆角 14px 的卡片：顶部为工作流名称、执行序号、时间与模式，右侧状态胶囊；步骤以浅底清单列在上方，结果在下方。
- 结果以「可直接使用」为先：音频与视频在卡片内直接播放（显示文件名、时长、格式、大小与下载按钮，视频可放大），图片与 3D 模型以缩略卡片打开预览。成片视频已包含旁白时，汇总区不再重复显示中间配音，配音仍可在对应步骤中查看。
- 步骤详情：顶部是执行路径标签和多次尝试时的分段切换；输入与输出并排成两个浅底面板（窄屏改为上下），字段名在左、值在右，小数值以等宽字体单行显示，不再放大成指标卡。
- 本地文件路径不作为正文展示，而是显示为带图标的文件名标签，悬停显示完整路径，可一键复制。若输出只包含文件路径和数值，且文件已能直接预览，原始数据折叠到「文件位置与原始数据」。

## 设置

- 设置页参考 Codex：左侧 200px 分类导航（外观、模型与账号、连接、插件、关于），右侧最大 760px 内容列。点击分类平滑滚动到对应分区，滚动时导航高亮跟随；900px 以下导航变为顶部横向分段，600px 以下主题卡改为单列。
- 每个分区由 15/22 标题、12/20 说明和一个圆角 12px 的分组卡组成，卡内设置行最小高度 60px、以细线分隔，标题 13px/500，说明 12px 次级色，控件靠右。主题卡用各自色板绘制缩略窗口；默认对话模型使用单选行；Codex 账号状态与登录入口、当前 Codex 模型放在「模型与账号」。插件目录沿用原有交互，按钮统一为 `tool-button` / `primary-button`。

## 对话与输出流

- 单一阅读列：消息、运行卡片与输入框共用最大 760px 的居中列，顶部只显示会话标题与当前模式。
- 用户消息右对齐，圆角 18px 气泡、14px 正文；附图排在气泡上方。Aura 回复不加气泡，以 14/24 正文直接排在页面上并按 Markdown 渲染（列表、代码块、行内代码），复制等操作在悬停、聚焦或最后一条时出现。
- 输入框参考 Codex：一张圆角 24px 的卡片，上方是输入区，下方一行从左到右依次为「+」、对话模式、留白、模型选择和圆形发送按钮，卡片下方不再放额外的设置行。「+」菜单收纳「添加图片」和「调用工作流」（也可直接粘贴图片或键入 /）。模型选择是一个按钮，显示「模型名 + 灰色思考强度」，点开后上方弹出菜单：模型列表（标出默认）、思考强度分段按钮，以及「仅影响当前会话」的说明；支持方向键、Esc 关闭并回到按钮。窄屏隐藏思考强度文字，只显示模型名。仅在演示模式下，卡片下方居中显示一行提示。消息在输入框上方渐隐，不会被硬切。

## 对话内图片输入

- 参考 Codex：输入框左下角「添加图片」按钮，也可在输入框任意位置直接粘贴（截图、浏览器复制的图片都支持）或把图片拖入输入框（拖入时整框高亮并提示「松开以添加图片」）。一条消息最多 4 张 PNG/JPEG/WebP，单张不超过 32 MB；选中即上传，缩略图排在文字上方，上传中显示转圈，失败标红，悬停可移除。上传完成前不能发送；只发图片不写文字也可以。本地演示模式不能附图，粘贴时会提示切换到 DSH 演示或 Codex 订阅。
- 发送后图片以缩略图显示在用户气泡上方，点击可在新标签页查看原图。会话只保存图片引用（内容哈希），不保存图片数据。
- Codex 模式把最近的最多 4 张图片随请求交给模型，历史中每条带图消息附「[用户附图：图1、图2]」标记；更早的图片只保留标记。演示模式与本地演示模型无法查看图片，输入框底部会提示。

## 对话内调用工作流

- 输入框左侧「+」或在空输入框键入 `/` 唤起工作流选择器。选择器浮在输入框上方，可按名称、用途或 ID 过滤，可运行的工作流在前；`/` 模式下焦点留在输入框，方向键选择、Enter/Tab 确认、Esc 关闭。不可用的工作流显示但不可选。
- 选中后输入框上方出现工作流标签，对话流末尾展开与绑定会话相同的内联参数块；已输入的文字会预填到第一个自由文本字段。提交后运行卡与普通消息按时间交错显示，同一会话可继续提问；运行结束后其结果才进入后续对话上下文。
- 普通会话中的运行在消息上记录 `workflow` 引用，待确认提交保存在会话的 `pendingWorkflow` 中并复用 requestId 重试，也可放弃。服务端历史只自动导入为独立的工作流会话，不会混入普通对话。

## 工作流与会话导航

- 点击卡片在该卡片下方展开整个节点图，再次点击收起；同一时间展开一个预览。编辑进入独立详情，只保留流程图、代码两个页签，返回回到列表。主导航的「工作流」始终返回卡片页。
- 桌面会话侧栏默认 280px，可在右边界拖拽调整到 240–480px，主区至少保留 560px；松手后保存宽度，刷新继续使用。边界支持方向键调宽、Home/End 与双击恢复默认。900px 以下改为 300px 原生抽屉；分栏生成助手根据主区实际可用宽度切换。
- 侧栏保持品牌、搜索、新对话、紧凑双列一级导航、工作台分组与底部设置；会话单行高 34px，默认右侧显示相对更新时间与执行状态图标。悬停、键盘聚焦或右键菜单打开时，时间与状态收起，原位置出现淡红色的归档按钮；没有常驻「…」按钮，会话操作（重命名、归档/恢复、进行中停止和删除确认）在该行的右键菜单里，键盘用 Shift+F10 或菜单键打开；触屏上没有悬浮状态，操作通过长按触发的右键菜单进入。有未结束执行的会话不可删除。状态图标覆盖生成、排队、暂停、等待输入、需要处理、失败、取消、中断与完成，悬停显示状态文字。归档与恢复都在顶部弹出 toast（5 秒自动消失，悬停或聚焦时暂停），带「撤销」按钮；toast 由 `toast.tsx` 的 ToastProvider 挂在 .aura-root 内，跟随主题。归档只改变本机会话列表，不停止执行或隐藏后端 run；「已归档」与全部记录页可检索、打开和恢复，轮询仍更新归档记录。
- 顶部用 38px 应用菜单栏加 48px 会话工具栏：前进/后退、侧栏切换、文件/编辑/视图/帮助菜单位于第一行；会话图标、实际任务标题、归档标记、执行状态、更多操作及账号位于第二行。普通对话不再重复占用一行标题。菜单支持方向键、Home/End、Escape 关闭与焦点返回，不会被会话滚动区截断。
- 运行按钮打开绑定工作流的会话，并在对话流末尾展开本次参数编辑块；表单/JSON 和演示/Codex 模式可切换。编辑块不使用模态层，不遮挡历史内容或阻塞页面滚动；提交确认后收起，顶部「再次运行」可再次展开，关闭时保留草稿。表单根据 JSON Schema 与字段语义选用多行描述、单行文字、数值、枚举、开关、图片路径和目录路径控件；主要输入独占一行，短参数可双列排列。桌面版的图片与目录控件调用原生选择器并仍允许手工修改路径，Web/移动端保留服务端路径输入。待确认请求在会话中保留独立提示与重试入口，复用原 requestId。
- 工作流历史使用与普通对话一致的中间输出区：每次输入右对齐，工作流回复左对齐；步骤按执行顺序直接显示并随轮询更新，最终结果接在步骤之后，不用外层大卡片包裹。回复头只保留工作流标识、状态、时间和停止操作，底部显示步骤进度与耗时。点击步骤可查看详细记录。输入输出按字段、列表和表格展示，Markdown 报告与 Agent 回复支持标题、列表、引用、表格和代码块；原始 JSON 与步骤详情按需展开。空报告明确提示未返回内容；不另外伪造完成结果。前端文本渲染使用 react-markdown / remark-gfm，禁用原始 HTML，保留默认 URL 过滤。
- 侧栏与全部记录页使用分支图标标识工作流会话，会话顶部显示绑定工作流，结果消息也带图标。普通会话继续独立生成；切换会话不停止后台工作流。
- 节点只包含输入、输出、Agent、工具、条件与循环；普通业务逻辑忽略，保留分支标签、循环回边和并行关系。画布使用纯色背景，取消加减缩放按钮，仅保留缩放读数和适应画布图标。鼠标滚轮围绕指针缩放；触摸板双指平移、捏合缩放；触屏单指拖拽、双指缩放及平移。浏览器没有通用的滚轮设备身份，因此平滑增量和刻度增量在一次手势内固定解释，Ctrl/Command + 滚轮明确缩放、Shift + 滚轮明确平移。聚焦画布后，方向键平移、加减号缩放、0 适应画布；聚焦节点后方向键仍移动节点。拖动节点时连线跟随，位置不写回工作流代码。
- 点击节点展开详情，可查看参数并跳到源码行。已注册源码保持只读，可从更多菜单复制到本地草稿编辑。草稿保留自动保存、导入/导出、Tab 缩进与撤销；助手代码可放入编辑器，源码只做静态解析。
