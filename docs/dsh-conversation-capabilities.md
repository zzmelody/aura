# DSH 对话能力

Aura 通过 DSH `0.2.1-rc.5` 的公开插件和服务提供上下文压缩、DeepSeek Web、只读子 Agent 与用户消息密钥遮罩，不修改 DSH 或 pi-ai 源码。

## 开启与请求记录

在“模型服务 → 对话能力”保存开关与 DeepSeek Web Key。新安装默认关闭自动压缩、Web 和子 Agent；读取设置不会创建用户配置。保存采用 revision 检查。设置在下次发送消息时更新工具列表。

每次标题提炼、压缩摘要、子 Agent 模型请求、目标模式模型请求、MCP 调用、单次 Search 或 Fetch 发出前，在 DSH storage domain `aura_coding_capabilities` 中预留一笔请求记录。所有这些能力均不设置累计请求次数额度，实际计费以模型与外部服务为准。崩溃、取消或失败后的未知结果保留在账本中，不阻止后续新请求，也不自动重发旧请求。原有 domain、v1 存储格式、历史记录和已保存的旧额度值保持兼容；旧额度值不参与执行判断，读取不迁移或改写配置。

Key 使用后端 DSH credentials 服务保存，配置和响应只包含是否已配置。设置界面不提供读取密钥功能。Flow 仍采用原来的显式工具授权。

## 自动标题

新主对话和侧边对话在首轮成功回复后，使用当前选择的模型把首条消息提炼为短标题。首条原文只用作临时标题。标题提炼无需设置额外请求额度；生成失败或取消时保留临时标题，不自动重试。

后续消息和重启恢复不重复生成标题；已有历史对话与固定的 Aura 主会话保持原名。标题不作为聊天消息，也不进入模型上下文。生成结果不能覆盖用户已修改的标题，关闭或归档后的迟到结果也不会生效。

## 上下文压缩

`/compact` 使用 DSH command registry 执行原生命令，仅允许空闲会话执行。没有可压缩历史时不发出摘要请求；正在压缩时可以停止。重启后可以先恢复会话再手动压缩。

自动压缩只在 Aura 对话的 step 边界调用原生 compaction policy，先使用原生工具结果裁剪，再视压力生成摘要。摘要沿用会话模型，自定义模型根据 context window 缩小摘要预留空间。摘要请求不自动重试；自动压缩失败或仍高于阈值会提示并继续当前轮次，过大的单条输入可能仍需用户拆分。

DSH 修改的是模型上下文投影，原始 JSONL 日志保留，Aura 历史仍显示原始消息。界面展示压缩进度；手动结果显示原生 token meter 估算的节省量。

## 运行中追加消息

运行中按回车或点击发送时，追加消息立即显示在当前回合，并标记「等待 Agent 读取」。服务确认接收后清除已提交的草稿，Agent 读取时移除同一条消息的提示。若回合已无法接收引导，Aura 移除临时消息、保留草稿和附件，并确认本轮是否结束。再次发送才会开启新一轮。

普通「停止」沿用 DSH 的保留 inbox 行为：停止本轮，已接收但未读的追加消息保留，界面显示「已保留，继续对话时读取」。下次发送「继续」或新问题时，由 DSH 在首个步骤读取原消息，再读取这次的新提问；Aura 不重新投递追加消息，也不因停止自动请求模型。历史和分页回放会恢复原消息的接收、读取状态，避免保留消息先于「继续」被读入时漏掉确认。真正关闭会话或释放 Agent 时，DSH 的取消记录显示为「已取消，未读取」。

## 执行记录与结论

Aura 的 `coder-v1` 在 DSH persona 中引导 Agent 在收尾回复里说明改动、已验证的结果和仍不确定的事项。工具结果进入当前轮次的后续模型步骤，结论来自该轮的 Agent 回复。

主对话和侧边对话在正常完成时把工具组、任务进度、阶段回复和文件改动收进顶部状态行。最终回复和交付文件直接显示。若 Agent 没有给出最终回复，界面只显示已有状态和记录。失败、停止或中途收到用户引导的轮次保留过程。重新打开历史会话时适用同样的规则。

## 图片附件

对话支持粘贴、拖入或选择 PNG、JPEG 和 WebP，每张图片最多 32 MiB。缩略图上的感叹号表示上传失败，具体原因显示在输入框上方。

## 分叉与复制

主对话和侧边对话的已完成回复下方都提供复制和分叉图标。复制取本轮回复正文。点击「分叉到新对话」打开独立草稿，首次发送时用 DSH 原生分叉继承截至所选回复的上下文。

最新回复的操作条常驻，旧回复在悬停或键盘聚焦时显示，触屏始终可见。复制成功后图标短暂变成勾。点击「用量」打开明细面板，查看本轮模型调用回报的精确总数、未缓存输入、输出和可用的缓存或推理明细。历史回放复用同一 DSH 原生计算，缺少完整用量数据时不展示数字。

## DeepSeek Search / Fetch

使用原生 `deepseek-search-api` 与 `deepseek-fetch-api`，官方 API 地址由 DSH 提供。没有启用或未配置 Key 时不向模型提供 Web 工具。每次 `web_search` 最多一个查询，使每笔请求记录对应一次 API 请求；结果数量、Fetch 输出上限与外部不可信内容提示由 DSH 负责。

`sendOriginalQuestion: false`，不会附带原始问题。Aura 展示来源链接、截断标记和 Fetch 状态。无自动切换服务或失败重发。

## 子 Agent

原生 spawn 工具提供两个独立预设：`coding-researcher`（只读调研）和 `coding-reviewer`（只读审查）。继承父会话模型和目录，最多同时两个，深度为一。允许文件读取、搜索、问答、向父 Agent 发消息，以及已经配置的 Web；不提供写文件、Shell、工作流、定时任务或进一步委派能力。

生命周期、通知、父子关系与恢复目录由 DSH 管理。Aura 提供状态、结果和停止入口；父会话停止时同时停止其子 Agent。子 Agent 问答路由到父对话，并标注来源。原生委派权限不允许子 Agent 自行扩权，需超出只读范围时交回父 Agent 处理。

标题栏「更多 → 子 Agent」打开 DSH 式紧凑目录，正文上方不再保留独立入口。当前选中的侧边对话也可从同一菜单查看自己的子 Agent。浮层列表展示任务、角色、状态与累计执行耗时，点击任务查看 Markdown 结果。支持键盘方向键、Esc 与窄屏；关闭后焦点回到「更多」按钮。停止只作用于选中的运行中子 Agent，打开过目录后即使父会话空闲仍更新子 Agent 状态。

「执行失败」表示该子 Agent 当前轮次确实以错误或输出上限结束，并提供安全错误说明。「记录读取失败」表示暂时无法确认执行结果，不视为任务失败；实时执行状态仍可用时保留「执行中」，否则显示「状态待确认」。已有结果保留并标明为上次读取的内容，可点击「重新读取」恢复。该操作只读取记录，不重新执行任务。子会话继承的父记录与自身旧轮次结果不用于判定当前任务已经完成。

重启只恢复子 Agent 状态和结果展示，不重新提交未知任务。

## 密钥遮罩

浏览器通过现有 DSH 模块加载器加载已发布的 `dsh-client-ui-secret-mask/client`。Aura 只提供 UserText matcher、locale 与 renderer 的注册适配；识别规则、遮罩和显示/隐藏按钮均使用原生实现，没有复制识别正则。

已发送、引导和待发送回合中的用户文本默认遮罩已识别的密钥。遮罩加载失败时暂不显示用户正文，避免短暂露出明文。遮罩只影响展示，历史、模型输入与原文复制不变，不能替代凭据管理，也不保证识别所有秘密格式。

## 工作空间规则

在工作空间根目录放置 `AGENTS.md`，Aura 会按会话绑定的目录将文件内容加载到该 Agent 的提示词。旁支和同目录的会话子 Agent 也会加载。跨工作空间分叉使用目标工作空间的规则，Flow Agent 使用自己的提示词。文件正文最多读取 64 KiB。

## 功能开关

在「设置 → 功能开关」按需开启 MCP、DSH 插件市场、SenseVoice 语音输入、Agent 团队和会话全文搜索。五项功能默认关闭，开关由 Aura 后端持久化。MCP 配置和开关设置通过仅绑定本机的 Aura 服务管理。

- **MCP** 支持 STDIO 和 Streamable HTTP。STDIO 的环境变量映射形如 `{"GITHUB_TOKEN":"AURA_MCP_GITHUB_TOKEN"}`，右侧为 Aura 后端进程的环境变量名。HTTP 可引用同类变量作为 Bearer 凭据。配置表单应填写变量名，实际值由后端读取。同名保存可更新连接。对话可在非只读权限下调用已连接的工具，每次调用预留一笔请求记录，不限制累计调用次数。
- **DSH 插件市场** 在「设置 → 插件」显示目录检索、版本和项目来源。同一设置页可按目录添加、启用或停用符合 Aura 插件清单的本机插件。市场条目是 DSH 扩展包，Aura 里的市场入口提供浏览。
- **语音输入** 首次使用前需要点击「准备模型」。准备下载约 239 MB 的 INT8 模型和附加文件。输入框麦克风每次录制至多 30 秒，在 Aura 服务设备上识别并插入当前草稿。
- **Agent 团队** 使用 DSH 的具名队友、消息和共享任务板。启用后可在对话中让 Agent 创建队友，点击对话标题栏的团队图标查看成员和任务。每个团队最多两个只读队友，每次队友模型请求预留一笔请求记录，不限制累计请求次数。团队和常规子 Agent 委派按当前开关选择。
- **会话全文搜索** 从工作空间对话标题栏打开，检索当前工作空间的主会话正文并跳转至结果。DSH 在首次查询时建立内存索引，关闭开关会释放该索引。

## 验证

默认测试使用本地合成模型、合成 Search / Fetch 响应及已发布的浏览器插件，不访问付费服务。覆盖无额度设置的并发请求、revision 冲突、未知结果不阻塞新请求与重启恢复、原生子 Agent 权限和重启、手动与自动压缩、遮罩及 API 无重试行为。合成测试不代表真实账号已完成付费联调。
