需求文件使用 docs/requirements/<唯一ID>.md，文件名只能含英文字母、数字、点、下划线和连字符。

示例：

---
status: 待处理
visual: false
---
# 需求标题

描述要实现的行为。

## 验收标准

- 写出可以通过测试或运行场景验证的结果。

如果需要截图验收，把 visual 改为 true，并在验收标准里写明场景、操作和预期画面。
每次推送可以包含多份需求。不要在需求文件中放密码、令牌或私有密钥。
CI 只在全部相关测试与视觉验收通过后，把 dev 上对应文档的状态改为“已完成”。
main 上的状态会在 dev 合回 main 后更新。失败时 dev 不会收到该需求的代码。
