# Aura 主题规范

方向：紧凑的创作工作台，圆角与侧栏布局参照 DeepSeek Harness 桌面端，默认配色保留 Aura 紫色系，支持用户显式选择自定义强调色。深色「夜航」与浅色「晨雾」都以中性色为底，默认紫色用于链接、开关与当前状态，主按钮搭配白色文字，悬停、选中、用户气泡与光晕使用同源的柔和色。以细分隔线、固定工具栏和独立滚动区域建立层级，减少卡片套叠与装饰占位。

基础颜色与排版来源是 `packages/frontend/ui/src/theme.ts`，通过 `@aura/ui/theme` 导出；自定义外观由 workbench 的 `appearance.ts` 在基础主题上派生，页面与组件通过主题上下文和 CSS 变量消费，不单独维护浅色页面。基础组件直接渲染标准 HTML 与 SVG，浏览器、Electron renderer 和 Capacitor WebView 使用同一套 CSS 语义。

macOS 桌面宽窗口在会话列表底色下使用系统侧栏材质。左栏以半透明的侧栏色叠加轻微冷色渐变，右侧对话直接绘制不透明的页面背景，分隔线绘制在主区一侧。系统开启「减少透明度」时，侧栏直接使用表中的实色。

悬停与选中使用 `soft` 柔紫色，不改变文字颜色；菜单、导航与筛选的高亮共用 `--highlight-fill`，由柔紫向透明渐变，以 `--highlight-sheen` 增加一条淡淡的顶部反光。选中的实底控件使用 `--control-fill` 紫色渐变；按下仍用 `pressed` 半透明紫色。主要操作（包括发送按钮）统一使用 `primary` / `primaryText`，保证白色文字与图标的对比度。细线 0.5px；圆角刻度 4 / 8 / 12 / 16 / 20，侧栏行与按钮 12px，卡片 16–20px。

输入区聚焦共用 `--focus-border`、`--focus-wash` 和 `--focus-shadow`：紫色细边、左上角渐隐的淡紫底光、2px 低透明度光圈与 16px 柔光。效果仅从主题 `accent`、`primary`、`soft`、`glow` 派生，不增加独立色板或循环扫光动画。复合搜索框、路径输入和对话卡片由外层承担焦点，内部输入不再叠加方框与光圈；独立输入框、文本域和下拉框直接使用同一组效果。失焦恢复原样，禁用项不出现交互高亮，错误与危险操作保留语义颜色。系统或应用开启减少动态效果时取消过渡；强制颜色模式使用系统高亮轮廓。

按钮共用悬停、按下、选中与键盘聚焦效果：普通与图标按钮悬停使用柔紫渐隐和轻微外光，按下改为更深的渐变与内阴影；主按钮、发送按钮及实底选中控件使用 `--control-fill`，悬停与按下分别采用同源的亮、暗渐变。危险操作使用红色派生效果，禁用按钮不产生交互光效。三种开关共用这套状态，开启时轨道为紫色渐变，关闭时恢复中性轨道；滑块位置、尺寸和语义保持不变。触屏不叠加按钮悬停效果，减少动态效果时停止开关滑块过渡。

含多个操作的组合行统一用 `data-row-highlight` 标记高亮主体，文字、关闭、归档等从属按钮使用 `row-control`：背景、按下和键盘焦点只绘制在整行上，内部按钮保持透明。该约定用于侧栏对话、工作区标题、已打开页面、工具标签、全部记录、工作流摘要与文件列表；行内菜单打开后仍由原行承接高亮。菜单中的图标、文本和快捷键同样共用菜单项的一层背景，不叠加局部圆角。独立开关、单选标记、文件类型标识和语义状态保留各自的状态展示。

## 字体与尺寸

界面默认使用系统字体栈（-apple-system、Segoe UI、PingFang SC、Microsoft YaHei），用户可选择宋体衬线或等宽界面字体，代码始终使用 SF Mono / JetBrains Mono 栈，都不打包或下载字体文件。CSS 通过 `var(--font-text)` 与 `var(--font-mono)` 引用，实际栈来自 `theme.ts` 的 `fontStacks`；共享组件的 `fonts` 引用相同的界面变量并提供默认回退。

外观页以「自定义外观」替代只读主题实验室：提供五个颜色预设、取色器、六位 HEX 输入、字体与圆角选择、即时预览和恢复默认。自定义强调色在深浅主题下派生 `accent/primary/soft/pressed/glow/user`，保证强调文字在页面、面板与着色背景上、白色按钮文字在主按钮上至少达到 4.5:1 对比度；用户选定的源色保留在控件中，语义状态色不覆盖。主题选择卡片同步预览当前的自定义色。

普通控件、面板和气泡的圆角通过 `calc(<原始尺寸> * var(--radius-scale, 1))` 缩放，直角、默认、柔和分别为 0、1、1.5，保留圆形和胶囊形控件。颜色、字体和缩放变量挂载到文档根，保证 portal 弹窗继承；插件使用这些变量可同步自定义外观。偏好单独保存到本机 `aura.appearance.v1`，读取不触发写入，损坏数据回退默认；恢复默认只清除此键，保留主题模式和其他用户数据，存储失败显示提示。

深色主题的长文使用柔和灰白正文，次级说明与过程信息逐级降低亮度。侧栏、菜单、输入框、其他页面与对话共用基础排版：普通文字、输入值、小字和标签默认为 400 字重，加粗与标题默认为 600，组件可用 500 等中间字重区分层次。强调通过字重表达，保持文字亮度平稳。宿主根节点与文档在 macOS 使用灰度抗锯齿，外部模态层继承同一效果。占位文字统一使用 `muted`，不额外叠加透明度；两种主题中的深色悬浮提示均使用 `tooltipText` 柔和灰白。文字色阶直接使用主题 token，宿主页面和插件保持一致。

主标题 28/38，页面标题 20/28（500），正文 14/22，说明文字 12/18。工作区控件以 12–14px 为主，代码为等宽 12px。主要间距级别为 4、8、12、16、24、32。顶栏从 72px 压缩为 48px，取消原有 1200px 总宽度限制。

## 动效

侧栏用 220ms 的减速曲线展开和收起。宽屏主区与侧栏边缘同步移动，macOS 标题在移动中让出系统导航位置。窄屏左侧抽屉的遮罩同步淡变，右侧工具、生成助手和任务详情使用全宽滑动视图。右侧面板在移动期间保持内容宽度，避免文字和终端反复折行。菜单用 130ms 淡入和 4px 位移提示层级变化。拖拽调整宽度时边缘直接跟随指针。系统或应用开启「减少动态效果」时直接切换。

## 图标

共享实现为 [`@aura/ui/icons.css`](../../packages/frontend/ui/src/icons.css)，由宿主入口加载一次，作用于 `.aura-root` 与 `.aura-modal` 内的 Lucide 和 `svg.aura-icon`。插件页面和结果视图直接使用同一套 class 与变量；独立 UI 入口可通过 `import "@aura/ui/icons.css"` 加载公开样式。颜色继续来自 `theme.ts`，线宽、尺寸和色阶工具类由这份 CSS 统一持有。

| 用途               | 描边或尺寸 | CSS 约定                                         |
| ------------------ | ---------- | ------------------------------------------------ |
| 普通线性图标       | 1.6        | Lucide 自动应用；自定义线性 SVG 添加 `aura-icon` |
| 主要操作，如发送   | 1.8        | `aura-icon--emphasis`                            |
| 大号占位图标       | 1.25       | `aura-icon--display`                             |
| 实心符号，如停止   | 0          | `aura-icon--filled`，SVG 保留所需 `fill`         |
| 小型状态与附属图标 | 12 / 14px  | `aura-icon--xs` / `aura-icon--sm`                |
| 常规与较大图标     | 16 / 20px  | `aura-icon--md` / `aura-icon--lg`                |

线性图标使用 24×24 的 `viewBox`、圆端点和圆连接。已有的 Lucide `size` 属性可以继续指定其他尺寸；尺寸工具类用于主动采用共享刻度。默认颜色继承父级 `currentColor`，与相邻文字、控件悬停和语义状态一起变化。普通操作使用 `secondary`，辅助图标使用 `muted`，选中与进度使用 `accent`；错误、成功与主按钮前景分别采用 `danger`、`success`、`primaryText`。对应颜色类为 `aura-icon--secondary/muted/text/accent/danger/success/on-primary`。使用颜色工具类时，Lucide 使用默认的 `currentColor`，避免同时传入会固定 SVG 描边颜色的 `color` 属性。

图标亮度通过色阶表达，禁用透明度由外层控件统一承担，避免父子两层衰减。悬停、按下和选中沿用控件的背景与颜色反馈，描边不随交互变粗；用于展开切换的显隐动画仍可使用 0/1 透明度。纯图标按钮提供 `aria-label`，其中的装饰 SVG 使用 `aria-hidden`。

```tsx
// Aura 插件页面内：宿主已加载共享样式。
<Search size={16} className="aura-icon--secondary" aria-hidden />
<LoaderCircle size={16} className="aura-icon--accent" aria-hidden />
<Globe2 size={40} className="aura-icon--display aura-icon--muted" aria-hidden />

// 自有线性图标也可采用同一套样式。
<svg
  className="aura-icon aura-icon--muted aura-icon--sm"
  viewBox="0 0 24 24"
  fill="none"
  stroke="currentColor"
  aria-hidden
>
  <path d="M4 12h16M12 4v16" />
</svg>
```

公开变量包括 `--aura-icon-stroke`、`--aura-icon-stroke-emphasis`、`--aura-icon-stroke-display`、`--aura-icon-size-xs/sm/md/lg`，以及分别映射到主题 `secondary/muted/accent` 的 `--aura-icon-color/muted/active`。局部定制线宽使用 `--aura-icon-stroke-width`，将变量放在需要定制的图标或区域上；日常界面优先使用已有刻度。品牌图形、流程连线、图表、媒体画布等不属于 UI 线性图标，保留自身几何；特殊 Lucide 或已标记的 SVG 可用 `aura-icon--custom` 显式保留原参数。插件通过公开 CSS 入口和宿主提供的 class/变量复用，源码保持在各自插件内。

## 组件

主要按钮提供默认、按下、禁用状态；次要按钮使用卡片色和细边。桌面图标按钮为 30–34px，主要按钮为 34–40px；触屏工作台操作扩大到至少 40px，并带明确的无障碍标签。卡片、主题选项、开关、输入框、对话气泡、生成状态与复制反馈使用统一语义颜色。页面右上角不展示任何模型后端的登录或连接状态徽标；Codex 授权入口位于设置的「模型与账号」，授权细节放在模态面板中，设备码必须支持复制。

页面与面板的主滚动容器必须铺满所属区域，纵向滚动条贴该区域右边缘；内容的居中、最大宽度和外侧留白放在滚动容器内部，不缩窄整个滚动容器。共享布局负责这一约束，不依赖按需加载页面的样式覆盖。代码块、表格、输入框等局部滚动条贴各自控件边缘。

页面断点以扣除侧栏后的可用宽度为准，主区使用 `workspace` 容器查询；只有窗口栏、侧栏抽屉与系统输入方式等全局行为使用视口媒体查询。主区不超过 820px 时，设置分类由左栏改为横向滚动导航，自动化详情改为全宽；设置内容区不超过 600px 时，主题选项和模型表单改为单列。工作流卡片在主区不超过 700px 时将操作放到下一行，参数、记录筛选和嵌套结果按可用空间换列、换行，长标题与路径允许收缩或换行。收窄后再拉宽应自动恢复布局，不改写用户布局配置。保留正文的阅读宽度上限，避免大窗口把段落无限拉长。菜单随窗口和所属面板尺寸重新定位，始终留在视口边界内；提示气泡在缩放、滚动时关闭，弹窗在短窗口内独立滚动。

设置分类切换独立页面，不在长页面中滚动定位；内容区一次只显示当前分类，切换后回到页顶，分类按钮以 `aria-current="page"` 标记当前位置。未打开页面不读取配置，已打开的表单在分类切换时保留草稿，隐藏页面不参与布局、键盘焦点和辅助技术浏览。当前应用会话记住选择的分类，工作台的管理插件入口仍可直接进入插件页。

对话区将用户气泡右对齐、回复左对齐。输入区固定在底部，模型选择与发送操作合并在一行。输入卡片聚焦时以主题 `accent` 细边高亮，主对话、旁支与演示对话保持一致；失焦恢复中性细边。逐字生成期间显示停止按钮；停止、网络错误和重试均为实际状态。外观设置支持自定义强调色、字体和圆角，并保留减少动态效果开关。

工作空间主对话与侧边对话共用内容宽度轴：正文自适应 680–920px，输入卡片比正文宽 32px，其内部文字与正文对齐；窄面板按可用宽度收缩。输出区两侧对称预留滚动条空间，长内容只在块内横向滚动。附件按钮为 28px，发送与停止为 34px 圆形按钮，图标居中；停止使用中性色填充。工具、AI 文字、问题、引导与嵌套工作流按事件顺序交错展示，完成后保留位置。工具授权使用输入框上方同宽的独立卡片，等待期间保留草稿并暂停发送，决定后在原时间线位置留下简短记录。

联网对话在输入框下增加紧凑的「模型 / 思考」设置行，使用后端 DSH 目录与原生可键盘操作的下拉框，右侧标注「仅本会话」。默认选项显示实际模型与档位；配置按会话保存，生成中禁用，不改变工作流 Agent。窄屏自动换行并扩大触控区域；目录加载失败显示重试，已保存的型号或档位不可用时明确提示。

## 动效

桌面启动使用近黑背景、紫色光核与倾斜轨道，页面直接绘制，无需视频或外部资源。启动层先于 React 工作台出现，首屏和在线工作空间、会话列表、模型目录准备好后自动收束到可见的 Aura 侧栏图标，侧栏隐藏时淡出；不强制播放完整动画。数据读取失败进入有明确错误和重试入口的工作台，模块加载失败保留启动层错误提示；减少动态效果时省略退场动画。启动层退出后移除遮罩、恢复键盘交互并释放动画资源。工作台和工作流列表点击直接显示，重型页面的加载提示限制在内容区，导航始终可用。

按压缩放约 110ms，入场透明度与 12px 位移约 420ms，轨道慢旋转 24 秒一周。装饰轨道与消息入场分开处理；流式文本不重复播放整段入场动画。

「减少动态效果」或系统的减少动态效果设置会关闭轨道旋转和入场过渡；按钮仍保留即时反馈。动画不能代替文字状态。主题选择、开关和导航提供可访问标签，键盘可发送或 Shift+Enter 换行。

## 信息架构

参考 Codex：新任务是首页，Aura 是独立的持久化个人助手，工作流是底层能力，工作台是面向任务的便捷入口。

顶部侧栏开关是展开/收起控件，使用 `aria-expanded`，常态保持透明。macOS 标题栏的拖拽热区与导航按钮区域互不重叠，侧栏展开与收起时都可直接点击切换；悬停、按下和键盘焦点沿用主题反馈。

- 侧栏自上而下：「新任务」按钮（38px）→ Aura 个人助手 → 工作流、自动化任务、工作台（行高 36px）→ 会话列表 → 底部工作区菜单。没有独立品牌行或重复的对话入口；收缩按钮只在顶部导航栏，小屏抽屉打开后将同一组导航移入模态层。Aura 使用 22px 呼吸轨道图标，生成时旋转加快，减少动态效果时静止；点击始终回到同一个主会话，助手不重复列入普通任务文件夹。会话列表头为 36px：左侧 14px 次级色「会话」（筛选时为「进行中」或「已归档」），右侧 28px 图标按钮依次为搜索、视图选项、添加工作区。搜索在列表头内展开为 32px 输入框（占位「搜索会话名称」，Esc 清空并收起，失焦且为空时收起）；视图选项菜单切换全部 / 仅显示进行中 / 仅显示已归档，筛选生效时按钮为紫色。工作区行 34px，图标随展开切换打开 / 关闭的文件夹，包含当前对话时为紫色，悬停时图标换成展开箭头并在右侧显示「更多操作」与「新会话」。会话行 32px（有自动化任务的对话在时间前显示 14px 闹钟标记）。
- 插件页：960px 居中列，按「内置插件」（仓库 `plugins/` 目录）与「已添加的插件」分组；每行 48px 图标、名称与版本、描述，右侧开关直接保存。目录增删留在设置页，通过「管理插件目录」跳转。
- 自动化任务页：任务是 DSH Schedule 提醒，到点后作为普通一轮投递进所选工作空间对话，工具范围与用户发送的轮次一致。列表含全部 / 运行中 / 已结束筛选与搜索；点击行在右侧 47% 打开详情（频率、下次运行、指令、运行记录）；新建与编辑使用模态表单，支持一次、每天、每周、间隔与 Cron。
- 图标按钮使用 DSH 式悬浮提示：深色 13/20 气泡、8px 圆角、悬停 500ms 后出现、键盘聚焦立即出现，空间不足时翻到另一侧；工作区行的提示显示名称与完整目录。
- 工作空间顶栏收为单行 48px：主区为标题、对话 / 执行记录菜单与工具面板开关，右区同一高度为混合工具标签、「＋」和收起图标。标签用图标区分侧边对话 / 终端，显示任务标题或 shell 名称，当前项浅底加下划线，溢出项通过列表菜单切换；方向键与 Home/End 可选标签。「＋」新建侧边对话或终端，不再叠放旁支标题、纵向列表和重复当前标题。收起按钮保留任务，标签「×」关闭对应工具；终端有任务或活动未知时弹出关闭确认。小于 648px 时工具占满主区，收起后回到主对话。侧边对话的「带回主对话」位于输入区附近，点击后追加到主对话草稿，保留来源对话并等待用户发送。
- 主对话和侧边对话的输入区为 24px 圆角卡片，输入与操作分成上下两层。输入自动增高，操作行左侧为「＋」，从侧栏顶部新建的任务在首次发送前可通过旁边的工作空间菜单选择或新建工作空间。工作空间行的「新会话」直接绑定该工作空间，输入框隐藏选择器。右侧为模型 / 思考强度和 34px 圆形发送按钮。附件、Skills 和 Flows 从「＋」进入，模型服务收纳在模型菜单内。操作位只显示一个按钮：生成中空草稿显示停止，有文字或图片时切换为发送，图片上传期间发送置灰；模型与思考强度允许为追加消息调整，发送后从后续模型调用生效。按输入卡片自身宽度隐藏思考强度和缩短工作空间标签，长模型名省略；不依赖演示页面的样式加载顺序。
- 所有对话输入区置底，空白对话也不居中；主对话与旁支底边对齐，多行内容向上增高，旁支结论入口与错误提示位于输入卡片上方。AI 文字之间的连续工具调用默认合并为可折叠摘要，保留数量、运行与失败状态；每组独立展开或通过轮次状态行统一控制，完成和流式更新不重置用户选择。文字、提问、引导和嵌套工作流保持原时间顺序。
- 工具摘要采用灰色扳手和动作短句，同类操作去重；正常完成时不堆叠勾选、次数和完成标签，次数移入提示，顶部完成状态简化为用时。摘要与正文左边缘对齐，悬停和键盘聚焦时显示折叠箭头；失败与中断仍以明确文字提示，未成功的修改不使用成功措辞。
- 对话轨迹：工作空间对话的「轨迹」标签。轨迹以会话事件时间绘制输入、模型、工具三条泳道，虚线分隔轮次，悬停显示步骤详情，拖动选择时间段放大并过滤下方步骤表。切换到轨迹时对话面板保持挂载，进行中的回复不中断。
- 默认进入新任务；上次打开 Aura 时刷新恢复助手。空白输入区置底，与已有对话保持一致；助手与任务的历史、模型选择和当前访问期间的文字草稿独立。
- 工作台与对话、工作流平级，直接由 App 渲染，不再挂在工作流列表页。三个工作台共用 `.studio-shell`：232px 项目栏 + 主区；主区顶部固定 52px 工具条（返回、项目标题与保存状态、操作），内容在 `.studio-scroll` 中独立滚动。900px 以下项目栏收起，工具条出现项目下拉。工作台页签使用分段控件，强调色统一取 `--accent` / `--primary`，不再使用各自的私有色或衬线标题。离开有未保存修改的工作台需要确认。

## 工作流输出

- 每次运行是一张圆角 14px 的卡片：顶部为工作流名称、执行序号、时间与模式，右侧状态胶囊；步骤以浅底清单列在上方，结果在下方。
- 结果以「可直接使用」为先：音频与视频在卡片内直接播放（显示文件名、时长、格式、大小与下载按钮，视频可放大），图片以缩略卡片打开预览；3D 模型以独立卡片直接在对话中展示，进入可视区域时按需加载查看器，支持拖动旋转、滚轮缩放、重置视角、放大与下载，参考图片和文件默认折叠。成片视频已包含旁白时，汇总区不再重复显示中间配音，配音仍可在对应步骤中查看。
- 步骤详情：顶部是执行路径标签和多次尝试时的分段切换；输入与输出并排成两个浅底面板（窄屏改为上下），字段名在左、值在右，小数值以等宽字体单行显示，不再放大成指标卡。
- 本地文件路径不作为正文展示，而是显示为带图标的文件名标签，悬停显示完整路径，可一键复制。若输出只包含文件路径和数值，且文件已能直接预览，原始数据折叠到「文件位置与原始数据」。

## 设置

- 设置页参考 Codex：左侧 200px 分类导航（外观、模型与账号、连接、插件、关于），右侧最大 760px 内容列。点击分类平滑滚动到对应分区，滚动时导航高亮跟随；900px 以下导航变为顶部横向分段，600px 以下主题卡改为单列。
- 每个分区由 15/22 标题、12/20 说明和一个圆角 12px 的分组卡组成，卡内设置行最小高度 60px、以细线分隔，标题 13px/500，说明 12px 次级色，控件靠右。主题卡用各自色板绘制缩略窗口；默认对话模型使用单选行；Codex 账号状态与登录入口、当前 Codex 模型放在「模型与账号」。插件目录沿用原有交互，按钮统一为 `tool-button` / `primary-button`。

## 对话与输出流

- 单一阅读列：消息、运行卡片与输入框共用最大 760px 的居中列。工作空间对话共用一条 48px 顶栏，以「工作空间 / 对话标题」显示上下文，完整目录悬停工作空间名称查看；首页不显示返回按钮。旁支操作与模型入口放在同一行，模型已配置时仅显示状态点和名称，悬停或无障碍标签提供完整配置状态。
- 用户消息右对齐，圆角 18px 气泡、14px 正文；附图排在气泡上方。Aura 回复不加气泡，以 14/24 正文直接排在页面上并按 Markdown 渲染（列表、代码块、行内代码），复制等操作在悬停、聚焦或最后一条时出现。
- 输入框参考 Codex：一张圆角 24px 的卡片，上方是输入区，下方一行从左到右依次为「+」、对话模式、留白、模型选择和圆形发送按钮，卡片下方不再放额外的设置行。「+」菜单收纳「添加图片」和「调用工作流」（也可直接粘贴图片或键入 /）。模型选择是一个按钮，显示「模型名 + 灰色思考强度」，点开后上方弹出菜单：模型列表（标出默认）、思考强度分段按钮，以及「仅影响当前会话」的说明；支持方向键、Esc 关闭并回到按钮。窄屏隐藏思考强度文字，只显示模型名。仅在演示模式下，卡片下方居中显示一行提示。消息在输入框上方渐隐，不会被硬切。

## 工作空间对话执行状态

- 执行过程保持 DSH 风格的可折叠标题与紧凑工具行。每轮请求和每次工具调用都展示明确状态：执行中使用转圈图标，完成使用绿色勾选，失败使用错误图标，主动停止与未返回结果的中断使用停止图标；工具类型图标仍保留，不依赖悬停或颜色来判断结果。
- 等待用户回答时，轮次标题改为提问图标，暂停转圈；回答后恢复执行状态。结束时保留耗时与操作次数，过程默认收起并可重新展开。实时和历史回放共用收尾逻辑，已结束轮次不保留仍在旋转的工具，也不将中断命令误报为成功。减少动态效果设置下保留图标与文字，但不播放旋转动画。

## 对话内图片输入

- 参考 Codex：输入框左下角「添加图片」按钮，也可在输入框任意位置直接粘贴（截图、浏览器复制的图片都支持）或把图片拖入输入框（拖入时整框高亮并提示「松开以添加图片」）。一条消息最多 4 张 PNG/JPEG/WebP，单张不超过 32 MB；选中即上传，缩略图排在文字上方，上传中显示转圈，失败标红，悬停可移除。上传完成前不能发送；只发图片不写文字也可以。本地演示模式不能附图，粘贴时会提示切换到 Codex 订阅或其他模式。
- 发送后图片以缩略图显示在用户气泡上方，点击可在新标签页查看原图。会话只保存图片引用（内容哈希），不保存图片数据。
- Codex 模式把最近的最多 4 张图片随请求交给模型，历史中每条带图消息附「[用户附图：图1、图2]」标记；更早的图片只保留标记。演示模式与本地演示模型无法查看图片，输入框底部会提示。

## 对话内调用工作流

- 输入框的快捷命令按钮和 `/` 唤起同一个紧凑菜单，参考 DSH Desktop 分为「内置命令 / Skills / Flows」子菜单，支持返回上一级；直接输入关键词跨类别搜索名称、用途或 ID。内置命令包含 `/model`、`/stop`、`/clear`（清空输入）；Skills 来自当前工作空间的 DSH 目录，选中插入 `/name ` 后填写任务并发送；Flows 沿用参数表单，可运行项优先，不可用项不可选。菜单锚定整个输入卡片的上边缘，左对齐、间隔 10px，宽 400px 并受视口约束，不随输入卡片拉伸；最高 320px，只有列表滚动，始终不遮挡输入框。弹层使用主题浮层色、16px 圆角和细边，搜索框为 8px 圆角的完整输入区，焦点反馈落在外层细边上；选中行使用柔紫底色和紫色图标，计数与说明保持次级色。标题区仅保留名称、返回与关闭，键盘提示置于底部细分隔线下；触屏隐藏键盘提示并扩大搜索框和图标按钮。`/` 模式下焦点留在输入框，方向键选择、Enter/Tab 确认，Esc、Shift+Tab 或外部点击关闭且保留草稿。
- 选中后输入框上方出现工作流标签，对话流末尾展开与绑定会话相同的内联参数块；已输入的文字会预填到第一个自由文本字段。提交后运行卡与普通消息按时间交错显示，同一会话可继续提问；运行结束后其结果才进入后续对话上下文。
- 普通会话中的运行在消息上记录 `workflow` 引用，待确认提交保存在会话的 `pendingWorkflow` 中并复用 requestId 重试，也可放弃。服务端历史只自动导入为独立的工作流会话，不会混入普通对话。

## 工作流与会话导航

- 点击卡片在该卡片下方展开整个节点图，再次点击收起；同一时间展开一个预览。编辑进入独立详情，只保留流程图、代码两个页签，返回回到列表。主导航的「工作流」始终返回卡片页。
- 桌面会话侧栏默认 280px，可在右边界拖拽调整到 240–480px，主区至少保留 560px；松手后保存宽度，刷新继续使用。边界支持方向键调宽、Home/End 与双击恢复默认。900px 以下改为 300px 原生抽屉；分栏生成助手根据主区实际可用宽度切换。
- 侧栏保持品牌、搜索、新对话、紧凑双列一级导航、工作台分组与底部设置；会话单行高 34px，右侧独立预留 72px，显示相对更新时间及进行中、暂停、等待输入、需要处理、失败等状态；完成与尚未开始不重复显示图标。悬停、键盘聚焦或右键菜单打开时，右侧信息切换为无底色的归档图标，图标悬浮时只加深颜色，标题宽度不变，长标题以省略号收尾；会话行不弹出重复标题和时间的原生提示，完整时间与状态保留在无障碍描述中。没有常驻「…」按钮，会话操作（重命名、归档/恢复、进行中停止和删除确认）在该行的右键菜单里，键盘用 Shift+F10 或菜单键打开；触屏上没有悬浮状态，操作通过长按触发的右键菜单进入，时间与状态始终可见。有未结束执行的会话不可删除。全部记录页仍展示完整状态，包括完成与尚未开始。归档与恢复都在顶部弹出 toast（5 秒自动消失，悬停或聚焦时暂停），带「撤销」按钮；toast 由 `toast.tsx` 的 ToastProvider 挂在 .aura-root 内，跟随主题。归档只改变本机会话列表，不停止执行或隐藏后端 run；「已归档」与全部记录页可检索、打开和恢复，轮询仍更新归档记录。
- macOS 桌面宽窗口（≥900px）的顶部共用一行 48px：左侧保留红绿灯与后退、前进、侧栏开关，页面标题和工具页签上移到同一行；收起侧栏后标题为左侧导航让位。拖动留白与可点击控件分别使用 drag / no-drag，侧栏内容从标题区下方开始。其他宿主和窄窗口继续使用独立导航行与 48px 会话工具栏。原分行布局中：第一行只保留后退、前进和侧栏开关，左下角「本地工作区」菜单仅保留深浅外观切换和设置；新任务、工作流与会话操作各自保留在主导航或会话入口，归档从视图筛选或设置进入。会话图标、实际任务标题、归档标记、执行状态、更多操作及账号位于第二行。普通对话不再重复占用一行标题。菜单支持方向键、Home/End、Escape 关闭与焦点返回，不会被会话滚动区截断，小屏在抽屉的模态层内展开。
- 运行按钮打开绑定工作流的会话，并在对话流末尾展开本次参数编辑块；表单/JSON 和演示/Codex 模式可切换。编辑块不使用模态层，不遮挡历史内容或阻塞页面滚动；提交确认后收起，顶部「再次运行」可再次展开，关闭时保留草稿。表单根据 JSON Schema 与字段语义选用多行描述、单行文字、数值、枚举、开关、图片路径和目录路径控件；主要输入独占一行，短参数可双列排列。桌面版的图片与目录控件调用原生选择器并仍允许手工修改路径，Web/移动端保留服务端路径输入。待确认请求在会话中保留独立提示与重试入口，复用原 requestId。
- 工作流历史使用与普通对话一致的中间输出区：每次输入右对齐，工作流回复左对齐；步骤按执行顺序直接显示并随轮询更新，最终结果接在步骤之后，不用外层大卡片包裹。回复头只保留工作流标识、状态、时间和停止操作，底部显示步骤进度与耗时。点击步骤可查看详细记录。输入输出按字段、列表和表格展示，Markdown 报告与 Agent 回复支持标题、列表、引用、表格和代码块；原始 JSON 与步骤详情按需展开。空报告明确提示未返回内容；不另外伪造完成结果。前端文本渲染使用 react-markdown / remark-gfm，禁用原始 HTML，保留默认 URL 过滤。
- 侧栏与全部记录页使用分支图标标识工作流会话，会话顶部显示绑定工作流，结果消息也带图标。普通会话继续独立生成；切换会话不停止后台工作流。
- 节点只包含输入、输出、Agent、工具、条件与循环；普通业务逻辑忽略，保留分支标签、循环回边和并行关系。画布使用纯色背景，取消加减缩放按钮，仅保留缩放读数和适应画布图标。鼠标滚轮围绕指针缩放；触摸板双指平移、捏合缩放；触屏单指拖拽、双指缩放及平移。浏览器没有通用的滚轮设备身份，因此平滑增量和刻度增量在一次手势内固定解释，Ctrl/Command + 滚轮明确缩放、Shift + 滚轮明确平移。聚焦画布后，方向键平移、加减号缩放、0 适应画布；聚焦节点后方向键仍移动节点。拖动节点时连线跟随，位置不写回工作流代码。
- 点击节点展开详情，可查看参数并跳到源码行。已注册源码保持只读，可从更多菜单复制到本地草稿编辑。草稿保留自动保存、导入/导出、Tab 缩进与撤销；助手代码可放入编辑器，源码只做静态解析。
